# EdgeForge 0.5.0 发布记录

- 开发日期：2026-08-10
- 状态：硬件验证通过
- 阶段：V5 Auto Tuning

## 目标

为 Triton MatMul 建立首个可复现的参数搜索闭环：生成候选配置，逐个编译、检查正确性和测量性能，保存完整搜索历史，选择最佳配置并回写 Kernel Registry。

## 当前实现

- 确定性 Grid Search、候选规范化、去重和最多 64 候选限制。
- `kernel_autotune` 任务、`tuning_runs` 数据库和 `autotune.candidate` / `autotune.completed` / `kernel.tuned` 事件。
- 最佳候选按 median、p95、compile time 和候选顺序选择，并写入 `kernels.metadata.tuning_config`。
- 调优后的普通 `kernel_pipeline` 自动复用最佳配置。
- Auto Tuning manifest 使用 SHA-256 内容寻址保存。

## 自动化与迁移验证

- 自动化测试：36/36 通过。
- Python compileall 与 `git diff --check`：通过。
- V4 数据库迁移：原有 1 个 release、3 个 Kernel、5 条 Benchmark、44 条 event、5 个 task 和 2 个 Artifact 全部保留；V5 仅增加当前 release 和空的 `tuning_runs` 表。

## RTX 4070 SUPER 真实验证

共享环境为 PyTorch 2.9.1+cu130、Triton 3.5.1。执行 MatMul `[256,256,256]`、FP16、4 个候选、每候选 5 次 warmup 和 10 次测量，4/4 correctness PASS。

| block_m | block_n | block_k | warps | stages | compile（ms） | median（ms） | p95（ms） |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 32 | 32 | 32 | 4 | 2 | 346.548 | 0.014416 | 0.021120 |
| 64 | 32 | 32 | 4 | 2 | 56.758 | 0.013392 | 0.019520 |
| 32 | 64 | 32 | 4 | 2 | 54.582 | 0.013312 | 0.019456 |
| 64 | 64 | 32 | 4 | 3 | 66.318 | 0.013248 | 0.018048 |

最佳配置为 `block_m=64, block_n=64, block_k=32, num_warps=4, num_stages=3`。随后使用最终源码重跑普通 Pipeline，任务快照正确携带该配置和 `backend=triton`，correctness PASS，median 为 0.014976 ms。

Auto Tuning manifest digest：`fa5a91b7d0e67d6a81b553c708308d35f3056a01dc053586da6acf0852f18732`。最终复用 Pipeline 的 compiler manifest digest：`a0848c3409b9dbfcceccc215e8aa400ea6953b478ac305236c7c1568f672308a`。两者记录的 Triton backend 源码 digest 均为 `e9c8b768d22f24372292df2f6363be8e62faec7e59708febda6d501763ca6728`，与冻结源码一致。
