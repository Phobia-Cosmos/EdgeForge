# EdgeForge 0.18.0 ISRUC medium experiment subset

- 日期：2026-09-04
- 状态：development snapshot；公开数据与 CPU smoke 验证完成
- 分支：`experiments/eeg-architecture-accuracy-lop`

## 数据契约

公开 medium subset 位于 `data/eeg-medium/isruc-v0.18.0/`，包含 20 个互斥 ISRUC-Sleep subjects、每个 subject 5 个 `(20,8,3000)` float32 文件及配对 `(20,)` int64 labels，共 2,000 epochs、约 183 MiB。

- source：subjects `1,3,4,6,7,9,10,21`，40 个文件。
- target：subjects `2,11,12,13,14,15,16,17`，40 个文件。
- retention：subjects `5,18,19,20`，20 个文件。

每个 subject 使用确定性的 `label-diversity` 排序选择 5 个文件。该选择适合开发和机制筛查，不保持原始人群类别比例，不能代替完整数据集上的科学评估。

## GitHub 边界

所有单文件约 1.83 MiB，远低于 GitHub 100 MiB 单文件硬限制；本次新增约 183 MiB，仓库累计体积仍明显低于通常建议控制的 1 GiB。未使用 Git LFS，其他机器普通 clone 后即可直接运行。

## 验证

- manifest：相对路径、公开来源、选择策略和 200 个 payload hashes。
- subject roles：无交集。
- label coverage：source、target train half、target evaluation half、retention 均为 5 类。
- benchmark target split：每个文件前 10 epoch adaptation，后 10 epoch held-out evaluation。
- scientific conclusion：不允许；medium subset 仅用于初步实验，正式 LoP 仍需完整 subject trajectory 和多 seed。
