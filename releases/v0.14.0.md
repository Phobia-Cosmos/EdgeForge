# EdgeForge 0.14.0 LoP matrix development snapshot

- 日期：2026-08-23
- 状态：development snapshot；不是部署稳定版，也不是 LoP 科学结论
- 范围：本地 RA-EEG matrix runner、cell bundle/catalog/audit 和可恢复版本日志

## 实现

- `scripts/run-raeeg-lop-matrix.py` 读取 `raeeg-lop-matrix-v1` manifest，展开 dataset × method × condition × subject × checkpoint stage，并为每个 cell 调用现有的只读 `brainuicl-instrumentation.py` 与 `brainuicl-fixed-budget-probe.py`；同时生成按 subject/seed/method 聚合的 trajectory catalog，供 lagged LoP audit 使用。
- 每个 cell 保存独立的 instrumentation/probe JSON、`edgeforge-bundle-v1`、命令 argv、stdout/stderr、status 和 configuration digest。成功结果自动汇总为 EdgeForge catalog，并调用本地 `lop-audit`；没有把实验提交到控制面，也没有修改外部 BrainUICL。
- runner 检查输出目录与所有输入根目录不重叠，拒绝不同 manifest 复用同一 run directory；`--dry-run` 和 resume 支持在长实验前检查计划并在中断后继续。

- `PYTHONPATH=src ... -m unittest discover -s tests -q`：`128/128 passed`。
- `config/raeeg-lop-matrix-v14-local-smoke.json`：ISRUC subject 1、seed 4321、finetune、clean condition、checkpoint stages 0/10；两个 cell 均 `succeeded`。stage 0 Transformer effective rank `7.8449817`，stage 10 `8.0745716`；这些是单 seed/单 subject smoke 指标。
- `config/raeeg-lop-matrix-v14-isruc-local.json`：ISRUC subject 2、seed 4321、clean condition 的 5 方法 × 4 stage 共 20 cells 均 `succeeded`。trajectory audit 为每个方法形成 3 个 lagged pairs，但所有方法都为 `insufficient-seeds`；没有方法获得科学结论许可。描述性汇总见 `matrix-report.md`，并记录参数 relative update 与 representation drift。
- `config/raeeg-lop-matrix-v14-faced-local-smoke.json`：FACED subject 1、seed 4321 的 pretrain/stage-1 mini-CL 两个 cell 均 `succeeded`；stage 0/1 Transformer effective rank 为 `10.14631/10.16186`，但 audit 因只有 1 个 transition 保持 `insufficient-pairs`。
- `config/raeeg-lop-matrix-v14-isruc-noise-local.json`：ISRUC subject 2 的 clean 与 noise severity 0.5 各 4 stages（finetune，共 8 cells）均 `succeeded`。noise 条件的 Transformer effective rank 为 `8.60024/8.54066/8.42969/8.59132`（stage 0/10/25/49），clean 对应为 `8.31961/8.29208/8.24665/8.41356`；这是单 seed、固定小文件预算的压力测试，不是 LoP 结论。
- `brainuicl-unlabeled-diagnostics.py` 的 ISRUC subject 2 pretrain smoke 成功：normalized predictive entropy `0.50197`、mean max-probability `0.71406`、noise-0.05 prediction agreement `1.0`；输出明确标记 `labels_loaded=false`、`optimizer_update=false`。
- FACED subject 1 pretrain 的无标签 smoke 也成功：normalized predictive entropy `0.30097`、mean max-probability `0.75749`、noise-0.05 prediction agreement `0.85`；该结果不构成 FACED LoP 结论。
- matrix runner 的 `--with-unlabeled-diagnostics` 单 cell smoke 成功，bundle 同时保存 predictor/outcome/diagnostic 三类 metric role；无标签诊断不会被 audit 当作 plasticity outcome。
- matrix dry-run 对本地 ISRUC smoke 报告 `ready_count=2`、`blocked_count=0`；缺 seed/stage 时会在执行前明确列出缺失 checkpoint 文件。
- matrix compact manifest 新增 `seeds` 展开；为 seed 4322/4323 配置但没有相应 checkpoint 时，dry-run 会逐 cell 标记 blocked，而不会复用 seed 4321。
- 多 seed preflight 实测 `12 cells = 4 ready + 8 blocked`；该记录用于规划真实 seed 重跑，不把缺失 checkpoint 当作实验失败数据。
- noise 对照 report 生成 4 个 paired clean-vs-noise stage deltas；例如 effective rank 的 noise-minus-clean 依次为 `+0.28063/+0.24858/+0.18304/+0.17776`，但 audit 仍为单 seed `insufficient-seeds`。
- ISRUC clean/noise 0.5 的 8-cell label-free matrix 全部成功；noise-minus-clean normalized entropy delta 为 `−0.01289/+0.00029/+0.00001/+0.00637`（stage 0/10/25/49），一致性 delta 为 0；这些是无标签可观测性变化，不是 LoP 结果。
- 合并 bundle 指标数分别为 486 和 525；catalog/audit 生成成功，audit 状态为单 seed 阻断（`scientific_conclusion_allowed=false`）。
