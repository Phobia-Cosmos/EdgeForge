# EdgeForge 0.8.0 发布记录

- 开发日期：2026-08-16
- 状态：验证通过
- 阶段：V8 Model Registry 与 Capability Gate

## 目标

在 V7 ExperimentRun、Metric 与 Artifact 证据链之上增加模型注册、固定能力门禁和可恢复生产状态；禁止跨 EEG 协议比较，也禁止 Gate、Worker 或 Agent 自动发布 production。

## 当前实现

- `models` Registry：candidate、accepted、rejected、production、rolled_back 状态。
- 不可变 `gate_policies` 和 `gate_evaluations`，保存完整 policy、metric、逐规则结果与实际 experiment task 快照。
- `workload + protocol + comparison_group` 三元硬边界和同 scope 单 production 约束。
- Model/Gate API 与 CLI；promote、显式 reject、生产切换和 rollback 都要求非空 reason 并写入事件。
- `config/raeeg-aligned-gate-v1.json` 固定 aligned-full49 验收阈值。

## Production 与 rollback 演练

Gate PASS 后 BrainUICL 和 SI 只进入 accepted。Operator 随后显式执行：

```text
BrainUICL accepted → production
SI accepted → production；BrainUICL → rolled_back
rollback SI → BrainUICL
```

最终状态为 BrainUICL `production`、Finetune `rejected`、SI `rolled_back`。数据库只存在一个同 scope production；事件保留两次 promote 和一次 rollback 的原因。

## 已知边界与后续规划

- 当前 Bearer Token 是控制面级权限，不提供个人 Operator 身份、双人审批或签名；V8 用“无自动 promote 路径 + 必填 reason + 事件”建立基础边界。
- checkpoint 尚未自动上传；V8 Model descriptor 明确记录 `component-digests-only`，不能把组件摘要误当单一 checkpoint Artifact。
- aligned policy 是基础设施验收策略，不是 LoP 科研结论，也不适用于 method-transfer。
- V9 将在 4070S 上实现真实 checkpoint 的 eager/`torch.compile` 模型级 Pipeline，将数值正确性、能力回归、compile time、graph break、steady latency 和显存串入下一层 Gate。
