## 当前证据边界

本机 x86_64 已成功执行 `target-probe` 和 synthetic model pipeline。该结果只验证控制面/Worker 接口，不是 Orange Pi 部署证据，也不是 BrainUICL 模型性能。

共享 `research` 环境的 PyTorch `2.11.0+cu130` 下，`config/model-pipeline-torch-eager.json` 与 `config/model-pipeline-torch-compile.json` 均在 CPU 上完成六阶段；`torch-compile` 使用 `backend=eager` 作为本机编译 contract，未宣称 CUDA 性能。

当前尚未写入 Orange Pi ARM64 probe、ONNX/IREE/RKNN Runtime correctness、真实模型离线 EEG inference 或板端性能数据。因此本版本保持 candidate，不创建稳定发布结论。IREE contract 继续 blocked，不下载 LLVM/IREE 源码，不填充伪造 source identity、binary 或 benchmark。

LoP 分析器不改变现有实验的科学状态。当前真实 LoP 数据仍只有 seed 4321，状态继续是 `blocked-by-checkpoint`；分析结果无论 status 是否为 `ok` 都固定 `scientific_conclusion_allowed=false`，只允许解释为描述性关联，不允许宣称因果机制。
