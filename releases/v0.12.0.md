# EdgeForge 0.12.0 V12 开发快照

- 日期：2026-08-20
- 状态：development snapshot，不是稳定发布
- 范围：异构目标探测与 Orange Pi/P550 Runtime 前置验证

## 已完成

- 新增 `edgeforge.target_probe` 和 `scripts/probe-target.py`，以只读方式采集 architecture、CPU、内存、DRM、`vulkaninfo`、IREE tools、RKNN Python 和 NPU device 状态。
- 实际 SSH 探测 Orange Pi：`aarch64`、8 cores、15964 MiB、RK3588 Linux、DRM 可见。
- 实际 SSH 探测 P550：`riscv64`、4 cores、25981 MiB、DRM 可见。
- Orange Pi 的系统 Python 只有 numpy，没有 torch/onnxruntime；P550 没有 numpy/torch/onnxruntime。两者均未发现 `vulkaninfo`、IREE tools、RKNN Python 或 `/dev/rknpu`。
- 当前两个目标均没有可用 Vulkan/IREE/RKNN/NPU 证据，因此没有注册虚假 backend，也没有运行伪造性能测试。
- 探测过程写入 `logs/v0.12.0/target-probe/`，原始 JSON 和校验清单归档到 `logs/archive/v0.12.0/target-probe-20260820/`。
- 新增部署 preflight；Orange Pi 的 BrainUICL ARM64 CPU manifest 因缺少 `torch_python` 被明确标记为 `BLOCKED`，未执行任何模型命令，结果写入 `logs/v0.12.0/deployment-preflight/`。

## 结论边界

本快照只证明目标设备可访问及其当前能力探测结果，不证明 Orange Pi NPU、Vulkan、IREE 或 RKNN 推理可用。下一步必须先在 ARM64 CPU 上加载真实 BrainUICL Artifact 并完成离线 EEG inference correctness，再决定条件性 IREE/Vulkan 路径。
