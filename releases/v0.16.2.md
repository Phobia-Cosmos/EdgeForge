# EdgeForge 0.16.2 RK3588 Vulkan userspace validation snapshot

- 日期：2026-08-25
- 状态：development snapshot；Orange Pi 的用户目录 `g610-g24p0` Vulkan API smoke、Mali OpenCL vector-add 和 RKNN board-runtime smoke 均通过；尚不是 EEG 模型部署稳定版，也不是科学结论
- 范围：增加可选 Vulkan ICD/loader override、用户目录 target probe、候选库 digest 绑定和 0.16.2 版本证据归档；不修改开发板系统包或系统 Vulkan 配置

## 实现

- `src/edgeforge/accelerator_probe.py` 的 `probe_vulkan` 支持 `icd_manifest`/`loader_library`，记录 manifest/library SHA-256，并在 probe 结束时恢复 `VK_ICD_FILENAMES`。
- `scripts/rk3588-accelerator-smoke.py` 与 `edgeforge accelerator-smoke` 暴露 `--vulkan-icd`/`--vulkan-loader`；远程模式只同步 EdgeForge probe 源码，候选库留在板端用户缓存。
- `src/edgeforge/target_probe.py` 与 `scripts/probe-target.py` 支持 `--vulkan-icd`，将用户目录 candidate 作为独立 evidence，不把文件存在直接升级为 capability correctness。

## Orange Pi 实测

- 板端：Orange Pi 5 Ultra，RK3588，aarch64，Ubuntu 22.04.5，kernel `6.1.43-rockchip-rk3588`。
- 系统 `libmali-valhall-g610-g13p0-x11-gbm` 和同源 `g13p0-gbm` 均缺少 Vulkan ICD loader entry points；control candidate 的 `vkCreateInstance` 为 `-9`，因此没有把它们登记为 Vulkan 驱动。
- 用户目录 `g610-g24p0-gbm` library digest 为 `4d7cb76a1d073c39a4fee34692e0422b1421ff258045a6cef40e9f91492c89a6`，manifest digest 为 `b35de60dd3478f8193a1aad4ff522ddec464edbd2cc2b5fd99367851d234b12f`。Vulkan loader API `1.3.204`，instance result `0`，physical device count `1`，设备名 `Mali-G610`，driver `DRIVER_ID_ARM_PROPRIETARY`。
- OpenCL `Mali-G610 r0p0` vector-add 256 元素最大绝对误差 `0.0`；RKNN 系统 Runtime API `1.4.0`、driver `0.9.6`，三次零输入 output SHA-256 一致，run median 约 `1.88 ms`（diagnostic only）。
- 使用同名 `orangepi` target probe、`vulkan` manifest `config/rk3588-vulkan-smoke-v1.json` 和 g24p0 full smoke 执行 deployment preflight，结果为 `PASS`；该 gate 只验证环境/API 证据，`execution_performed=false`，不代表模型已部署。

## 复现与门禁

```sh
PYTHONPATH=src python3 scripts/probe-target.py --name orangepi --ssh-host orangepi --version 0.16.2 --vulkan-icd /home/orangepi/.cache/edgeforge/rk3588-vulkan-g24p0/icd/mali-g610-g24p0.json --output .edgeforge/v0.16.2-target-probe-orangepi-g24p0.json --log-dir logs
PYTHONPATH=src python3 scripts/rk3588-accelerator-smoke.py --name orangepi-all-g24p0 --ssh-host orangepi --version 0.16.2 --vulkan-icd /home/orangepi/.cache/edgeforge/rk3588-vulkan-g24p0/icd/mali-g610-g24p0.json --repeat 3 --output .edgeforge/rk3588-accelerator-smoke-v0.16.2-g24p0.json --log-dir logs
```

`logs/archive/v0.16.2/rk3588-vulkan-userspace-audit/` 保存 target probe、g13p0 control、g24p0 full smoke、命令输出、测试日志、候选库/manifest metadata、release 说明和 `SHA256SUMS`。Vulkan probe 的成功级别是 loader → instance → physical-device enumeration；要解锁模型 backend，仍必须追加编译 artifact、算子覆盖、模型 numerical correctness 和 benchmark 证据。
