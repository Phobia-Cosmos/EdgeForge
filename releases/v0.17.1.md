# EdgeForge 0.17.1 可公开 ISRUC mini split

- 日期：2026-09-04
- 状态：development snapshot；数据与 CPU smoke 验证完成
- 分支：`experiments/eeg-architecture-accuracy-lop`

## 数据变更

本版本将 ISRUC-Sleep processed mini split 纳入 Git：source subjects 为 `1,3,4`，target subject 为 `2`，retention subject 为 `5`，每个 subject 一个 `(20,8,3000)` float32 data 文件和对应 `(20,)` int64 label 文件。使用 `label-diversity` 策略优先选择前后半段都具有类别覆盖的 sequence，解决 v0.17.0 首文件抽样导致 target/retention 全为类别 0 的 ceiling 问题。

公开 manifest 使用相对路径并保存原始与发布副本 SHA-256，不记录本机数据根目录。该子集只用于接口测试、CPU smoke 和初步架构比较，不代表完整 ISRUC 分布，也不足以支持 LoP 科学结论。

## 授权与来源

ISRUC-Sleep 是公开数据集；仓库所有者已明确确认该 mini subset 可以上传。原始来源与规范引用记录在 `data/eeg-mini/isruc-v0.17.1/DATASET_CARD.md`。本仓库的代码许可证不自动替代或扩张上游数据条款。

## 验证

- payload：10 个 `.npy` 文件，共约 9.3 MiB；单文件约 1.83 MiB。
- source label coverage：classes `0,1,2,3,4`。
- target/retention coverage：各 4 类；target adaptation/evaluation halves 各 3 类。
- manifest source/output hashes：全部一致。
- CPU benchmark：`lop_mlp/eegnet/tcn/transformer/brainuicl` 单 seed smoke 全部完成。
