# EdgeForge 0.4.0 发布记录

- 开发日期：2026-08-10
- 状态：硬件验证通过
- 阶段：V4 Artifact Store 与 Compiler Pipeline

## 目标

把 Kernel Registry 扩展为可执行的 `compile -> correctness -> benchmark` 流水线，并用内容寻址 Artifact Store 保存编译 manifest、工具链信息和实现 digest。

## 当前实现

- SHA-256 内容寻址 Artifact Store，重复上传相同内容不会生成第二份 blob。
- Artifact 元数据、Kernel artifact digest、Benchmark compile time 与 artifact digest 持久化。
- `kernel_pipeline` 任务和 compile/correctness/benchmark 结构化阶段事件。
- 所有架构可用的 Python reference compiler pipeline。
- RTX 4070S 可用的 Triton MatMul backend，使用共享 PyTorch/Triton 环境。
