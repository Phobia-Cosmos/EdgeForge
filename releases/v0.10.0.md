# EdgeForge 0.10.0 发布验证

- 日期：2026-08-19
- 范围：模型级 frontend/transform/compiler/runtime 基础设施
- 版本：`0.10.0`

## 自动化验证

执行：`PYTHONPATH=src python3 -m unittest discover -s tests -q`

结果：`63/63` 通过。

覆盖内容包括 Model manifest 校验、transform digest、外部 stage 的 allow-list 与 cwd 边界、模型 compiler manifest Artifact、`model_runs` SQLite/API 持久化，以及既有 Operator/Kernel/Experiment/Capability Gate 回归。

另外使用 `config/model-pipeline-synthetic.json` 和 `scripts/model-pipeline-reference.py` 在本机完成一次六 stage 闭环：`export=0`、`transform=0`、`compile=0`、`run=0`、`correctness=0`、`benchmark=0`，correctness 为 `true`。该 benchmark 仅是标准库 reference baseline，不能代表 4070S、Orange Pi 或任何真实 Backend 性能。

## 运行边界

本版本没有宣称真实 PyTorch、ONNX Runtime、IREE 编译产物或开发板性能。Reference adapter 只用于验证契约、Artifact 和日志闭环；接入 BrainUICL 时必须替换为受信任工作区内真实命令和数据集 manifest digest 后才可作为研究结果。Orange Pi 若缺少目标 Runtime，应记录 failed 或 capability blocked。

## 日志与数据库

正式运行需将 `EDGEFORGE_LOG_DIR/v0.10.0/`、控制面 SQLite（含 WAL checkpoint 后的备份）和 `model-compiler-manifest` Artifact 一并归档；不覆盖旧版本日志。
