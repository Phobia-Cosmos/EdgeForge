# EdgeForge 0.13.0 LoP instrumentation development snapshot

- 日期：2026-08-22
- 状态：development snapshot，不是稳定发布
- 范围：BrainUICL/RA-EEG 指标 instrumentation、固定预算 probe、FACED/ISRUC 数据 shift manifest 与 LoP schema 兼容性

## 已完成

- 新增 `scripts/brainuicl-instrumentation.py`，以只读方式支持 ISRUC `(20,8,3000)` 与 FACED `(20,32,2500)`，输出 representation spectra、attention entropy、activation near-zero/dormancy、经验 Fisher、梯度 Gram、权重范数、最后层 Jacobian feature-factor、checkpoint drift 和局部线性有限差分。
- 保留 EdgeForge 默认 predictor `task.spectra.transformer_1.effective_rank`，并为历史 `task.spectra.transformer.effective_rank` 与 `task.plasticity.acc_gain` 提供分析 alias；不再把同一个重复调用的 attention module 虚构成三个独立参数层。
- 新增 `scripts/brainuicl-fixed-budget-probe.py`，记录 held-out loss/accuracy/macro-F1 曲线、AULC、fresh gap 和 probe curve step；明确 supervised-oracle 诊断边界。
- 新增 `scripts/generate-raeeg-shift.py`，生成 amplitude/noise/channel-dropout/time-jitter/bandstop 的 provenance-preserving 派生数据，不修改 canonical dataset。
- normalizer 支持 list-of-dict learning curves、checkpoint-stage fallback、稳定 context 配对和新增诊断 namespace；exact LoP pairing 忽略 measurement-only `probe_budget`/`measurement_protocol`，但保留它们用于审计。
- 新增 [docs/lop-eeg-unified-plan-20260822.md](../docs/lop-eeg-unified-plan-20260822.md)，回答统一数学推导中的 Jacobian、谱、交叉熵曲率、RL 迁移边界和 FACED/ISRUC 数据修改实验设计。

## 真实验证

- 4070 SUPER、共享 `brainuicl` 环境 PyTorch 2.9.1+cu130：ISRUC seed 4321 pretrain subject 1 instrumentation smoke 成功，Transformer effective rank `7.84498`、stable rank `2.37688`、actual `softmax(dim=1)` attention entropy `1.66083`。
- FACED seed 4321 pretrain subject `sub-001` instrumentation smoke 成功，Transformer effective rank `10.14631`、stable rank `2.01167`。
- 使用 5 个真实 FACED subject 的只读 symlink mini-split，在外部 BrainUICL runner 上完成 finetune 1-task/1-epoch checkpoint smoke；EdgeForge 随后成功采集 stage 1 drift 与 fixed-budget outcome。该 mini-split 只验证接口和日志链路，不作为 FACED 方法结论。
- ISRUC finetune seed 4321 stages `0/10/25/49` 的 checkpoint instrumentation 与 fixed-budget probe 成功；多阶段 audit 能配对 3 个 lagged transitions，但只有 1 个真实 seed，状态为 `insufficient-seeds`，`scientific_conclusion_allowed=false`。
- 全量 BrainUICL 819 个结果文件的只读 audit：`814 missing-predictor`、`2 candidate`（只有 stage 0，无法形成 lagged pair）、`3 analysis-blocked`；没有从旧 accuracy/plasticity 标量反推 effective rank。
- EdgeForge 自动化测试：`112/112 passed`。

## 证据边界与后续

本快照没有声称 FACED 或 ISRUC 已发生 LoP，也没有声称任一数据 shift 会导致 LoP。下一步必须为每个数据集和方法生成至少 3 个真实 seed 的连续 checkpoint，校准 fresh probe 的预算/学习率，再进行 clean → 单因素 shift → 组合 shift 的预注册实验。小型受控 shift payload 保存在共享数据盘 `/home/undefined/Disk/datasets/edgeforge-raeeg-shifts/v0.13.0/`，完整 JSON、catalog、audit、smoke 和 SHA-256 清单位于 `logs/archive/v0.13.0/lop-instrumentation-20260822/`。
