# EdgeForge 0.1.0 发布记录

- 发布时间：2026-08-10
- 状态：历史稳定基线
- 阶段：V1 异构基础设施

## 交付内容

完成 Worker Registry、Heartbeat、动态能力发现、SQLite Task State Machine、硬约束调度、Worker pull 模型、受控命令执行、Benchmark 重复运行、日志与结果回传、CLI 和 systemd 模板。

## 真实硬件验证

四个节点均成功注册和执行相同 Python workload：RTX 4070S 主机 `x86_64` 中位耗时约 20 ms；Orange Pi `aarch64` 约 77 ms；Meles `riscv64/C910` 约 177 ms；P550 `riscv64/EIC7700` 约 251 ms。该结果仅验证跨架构任务闭环，不作为 AI Kernel 性能结论。

## 自动化验证

- 单元与 HTTP 集成测试：14/14 通过。
- Python compileall：通过。
- 未鉴权控制面请求：正确返回 HTTP 401。
- 临时验证服务与测试令牌在验证完成后已停止使用。

## 已知边界

V1 尚无 Operator IR、独立 Performance Database、Kernel Registry、模型 Runtime 或 Agent。命令 stdout/stderr 保存在任务结果中，尚未形成按版本分区的文件日志与结构化事件表。
