# Gain-drift10 medium ISRUC visualizations v3

This revision uses complete 30-second epochs, all target epochs and all eight channels from the medium ISRUC gain-drift10 condition. Black lines mark file boundaries; white dotted lines mark adaptation/evaluation boundaries. Raw waveform panels use per-subject y-scales so acquisition gain does not hide low-amplitude subjects. These figures describe input drift and do not by themselves establish LoP.
