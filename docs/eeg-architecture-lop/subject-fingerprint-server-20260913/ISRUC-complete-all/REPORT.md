# ISRUC complete CPU fingerprint analysis

All 98 subjects, 4276 sequences and 85520 epochs were processed. Each subject has a complete profile and per-sequence median/MAD in `subjects/`.

Nearest-centroid accuracy: 0.1470; logistic identity probe accuracy: 0.7328; between/within profile distance ratio: 1.0762.

This is a descriptive identity-separability analysis, not an LoP claim. The profiles are constraints for later subject-preserving transformations.
