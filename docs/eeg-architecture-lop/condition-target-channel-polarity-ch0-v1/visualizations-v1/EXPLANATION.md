# visualizations-v1

本目录只保留图片；机器可读文件已归档到 `eeg-architecture-lop-analysis-20260911/` 下的同一相对路径。
这些图片是描述性 EEG/LoP 诊断，不能单独作为 LoP 结论；LoP 必须查看对应实验的 fresh-gap 严格 gate。

## 图片说明

- `eeg-polarity-channel-correlation.png`：极性对照图：验证通道翻转后的波形镜像、PSD 保持和相关系数变化。
- `eeg-polarity-waveform-and-psd.png`：波形图：比较个体或条件下的时域 EEG 形状与幅度。
