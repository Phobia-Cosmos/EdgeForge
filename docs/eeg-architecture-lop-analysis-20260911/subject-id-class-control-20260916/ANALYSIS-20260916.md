# EEG subject-ID 特征分析阶段报告（2026-09-16）

## 结论摘要

本阶段把“只看 EEG，不看睡眠/情绪 class，能否判断 subject ID”拆成三个可复现实验问题：已登记 subject 的闭集识别、未登记 subject 的开放集拒识，以及固定 task class 后的身份解码。ISRUC 和 FACED 都显示，BrainUICL 的 EEG/frontend 表征包含稳定的 subject-specific information；但当前证据是 representation-level decodability，不是生物认证结论，也不是 LoP 结论。

最重要的控制是 task-class-conditioned probe。只用每个 sequence 的 sleep/emotion class histogram 时，ISRUC 的 top-1 为 2.31% ± 0.21%，FACED 为 0.07% ± 0.12%，分别接近 98/123 个 subject 的机会水平 1.02%/0.81%。固定 task class、并对每个 subject 使用相同数量的 train/test epoch 后，ISRUC 的 EEG branch 为 26.29% ± 0.41%，Transformer layer 1 为 24.50% ± 1.22%；FACED 的 EEG branch 为 25.63% ± 1.40%，Transformer layer 1 为 25.60% ± 4.16%。因此身份解码不能仅由 task-label 组成差异解释。

## 实验协议

每个 `.npy` 文件作为不可拆分的完整 group/sequence：ISRUC 为 20 × 8 × 3000，FACED 为 20 × 32 × 2500。对每个 subject，将完整 group 随机分成 enrollment/train 与 held-out/test，所有切分都在 group 层完成，避免同一 sequence 的相邻 epoch 泄漏到两边。每一个表示都冻结，subject ID 由独立的 `StandardScaler → 可选 PCA(64) → class-balanced RidgeClassifier` 解码；该 probe 不改变 BrainUICL 原来的睡眠/情绪训练目标。

多 seed 使用 4321、4322、4323。FACED 三个 seed 同时使用了对应 seed 的 pretrain checkpoint；ISRUC 目前只有 `feature_*_parameter_4321.pkl`，因此 4322/4323 表示不同 group split seed、同一冻结 pretrain checkpoint，不能被误称为三个独立模型 seed。每个运行的 stdout/stderr 保存在对应目录的 `run.log`，输入、checkpoint、seed、设备和样本数量保存在 `summary.json`。

## 闭集与开放集结果

闭集指标回答“新 group 能否分配给已经 enrollment 的 subject”；开放集 AUROC 回答“能否判断它是不是已登记 subject”，不能给未见 subject 凭空生成具体 ID。

| dataset | representation | known top-1 | unknown AUROC |
| --- | --- | ---: | ---: |
| ISRUC | raw waveform | 4.00% ± 0.40% | 0.4953 ± 0.0596 |
| ISRUC | EEG branch | 76.11% ± 0.91% | 0.6822 ± 0.0354 |
| ISRUC | Transformer layer 1 | 54.48% ± 1.41% | 0.5808 ± 0.0071 |
| ISRUC | classifier input | 30.63% ± 0.66% | 0.5143 ± 0.0107 |
| FACED | raw waveform | 4.00% ± 1.06% | 0.5130 ± 0.0162 |
| FACED | EEG branch | 85.88% ± 0.82% | 0.7852 ± 0.0351 |
| FACED | Transformer layer 1 | 62.84% ± 1.85% | 0.6442 ± 0.0604 |
| FACED | classifier input | 26.70% ± 1.03% | 0.5295 ± 0.0078 |

sequence aggregation 明显增强身份稳定性。以 EEG branch 为例，ISRUC 的 1/5/20 epoch 聚合 top-1 为 37.16%/59.62%/76.11%，FACED 为 15.22%/55.27%/85.88%。这支持“跨 epoch 的稳定成分通过聚合提高信噪比”，但不表示任意单个 epoch 都能可靠认证个体。

## 固定 task class 的控制结果

class-conditioned 实验在每个 task class 内只保留同时拥有足够 train/test epoch 的 subject，并对每个 subject 采样同样数量的 epoch。这样可以避免某些 subject 因睡眠阶段或情绪比例不同而被线性 probe 识别。

| dataset | task histogram top-1 | raw waveform | EEG branch | Transformer layer 1 | classifier input |
| --- | ---: | ---: | ---: | ---: | ---: |
| ISRUC | 2.31% ± 0.21% | 1.45% ± 0.29% | 26.29% ± 0.41% | 24.50% ± 1.22% | 12.97% ± 0.74% |
| FACED | 0.07% ± 0.12% | 2.61% ± 0.04% | 25.63% ± 1.40% | 25.60% ± 4.16% | 16.80% ± 0.77% |

这里的 raw waveform 接近机会水平，而卷积 frontend 和早期 Transformer 表示仍有较强可解码性。可能来源包括个体生理差异，也可能包括 session、参考电极、阻抗、增益、通道布局、设备或预处理批次线索；当前实验不能把它们分开。

## 对 RQ1–RQ3 的回答

### RQ1：EEG 中是否存在可识别的 subject-specific information？

是。在已登记 subject 的 group-disjoint 闭集协议中，EEG branch 的 sequence top-1 远高于 1/N 机会水平；在固定 task class 后仍显著高于机会水平。因此数据和冻结表征中存在可重复的 subject-specific statistical cues。对完全未登记 subject，系统只能做 unknown rejection，不能直接输出其真实 subject ID。

### RQ2：单 epoch 与 sequence 层面的强度有何差异？

sequence 聚合比单 epoch 更稳定，因为 median/平均聚合削弱瞬态状态和噪声。当前 Transformer token 是完整 20-token 输入后的 contextual token，不能严格称为“独立单 epoch”。严格单 epoch 结论应使用 raw/frontend tap，或另行实现长度为 1、attention mask 和不共享其他 epoch 的 Transformer 推理路径。下一步粒度可进一步缩短到 1–5 秒窗口，但需要独立 recording/session split，避免把同一 recording 的窗口当作独立证据。

### RQ3：持续学习是否吸收或记忆 subject characteristics？

冻结 pretrain 结果只证明表示含有身份线索。已有 checkpoint 对照显示 ISRUC EEG branch sequence top-1 从 Pretrain 的 75.41% 变为 `individual_1` 的 76.45% 和 `individual_38` 的 77.15%，Transformer layer 1 从 52.84% 变为 56.38% 和 56.15%；unknown AUROC 也发生变化。它们提示持续学习会重编码 subject-specific characteristics，但不能单独证明模型“记住了某个人”，更不能单独证明 LoP。需要逐 checkpoint、逐 subject transition、至少三个独立 model seed，并同时记录 task accuracy、旧 subject retention、fresh-subject adaptation、effective rank、谱和梯度覆盖。

## 可解释性与边界

可解释候选特征包括每通道 log-RMS、去中心化 RMS、差分粗糙度、频带相对功率、谱熵、通道间相关结构和 EOG/EEG 混合模式。增益归一化、参考变换、通道置换、频带遮蔽、相位随机化和通道遮挡是区分“生理身份”与“采集侧信道”的必要消融。单纯把 probe accuracy 叫作 fingerprint uniqueness 是不恰当的；应进一步报告 verification 的 EER/FAR/FRR、session-disjoint 泛化和 unknown calibration。

当前结果不支持以下表述：

- “可以根据一个 epoch 确认真实身份”；
- “深层网络已经删除了所有身份信息”；
- “身份 probe 上升就是 LoP”；
- “固定 class 后的高分一定来自生理差异”。

## 下一阶段执行计划

1. 从原始元数据恢复明确的 recording/session 标签，执行 session/file-disjoint split，并复跑 sequence、epoch 和 class-conditioned probe。
2. 加入 raw gain normalization、channel-wise z-score、reference normalization、band masking、phase randomization 和 channel occlusion，形成身份线索贡献矩阵；每个条件同时记录 task accuracy。
3. 固定一套 identity probe，在 continual-learning 每个 checkpoint 上追踪 enrolled subject、未见 subject 和新 subject 三组，联合 LoP 的 fresh-vs-warm、AULC、effective rank、谱、梯度覆盖与 retention 指标。
4. 建立普通 fine-tuning、replay 和 subject-adversarial/domain-invariant 三条对照流，使用至少三个独立 model seed；只有身份变化与 fresh-task 学习退化共同出现时，才讨论其与 LoP 的关系。
