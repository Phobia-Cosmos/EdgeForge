# 09-15 EEG 个体特征与编码后表征分析

本报告对应 `EEG基础网络LoP指标分析与实验方案.md` 中 2026-09-15 的问题。分析只读取本地数据和 checkpoint，不修改原始数据。所有身份 probe 都使用被试内 sequence/trial 留出，因此结果表示跨记录组的可重复性，不是单个 epoch 的生物识别认证结论。

## 数据级结果

ISRUC 使用 98 个被试、85,520 个 30 秒 epoch、83 维波形/频谱/连接特征。每个被试前半部分 sequence 用于训练身份 probe，后半部分完整 sequence 留出。最近邻中心分类准确率为 0.2372，Logistic 身份 probe 准确率为 0.7325，平衡准确率为 0.7311，被试间中心距离与被试内半径之比为 0.9542。ISRUC 的信号包含可重复的个体差异，但睡眠阶段和跨 sequence 状态变化较大，使单纯中心分类受到影响。

FACED 使用 123 个被试、3,444 个 trial，每个被试 28 个视频 trial；从每个 trial 的 onset 读取前 20 秒 BDF EEG，得到 323 维特征。前 14 个 trial 形成被试 profile，后 14 个 trial 留出。最近邻中心准确率为 0.9413，Logistic 身份 probe 准确率为 0.9861，平衡准确率为 0.9861，被试间中心距离与被试内半径之比为 2.5928。FACED 的跨视频 trial 身份可分性很强，但可能混合了电极增益、参考、采集批次和视频/状态效应；需要增益校正、session-disjoint 和按情绪类别平衡后再作生理解释。

两套结果共同支持“EEG 输入含有跨记录可重复的个体信息”，但不能直接推出模型已经学习了身份，也不能把身份可分性当作 LoP。身份 probe 的机会水平分别约为 1/98 和 1/123，必须报告完整混淆矩阵、类别平衡、session 信息和增益消融。

## 编码后 BrainUICL 诊断

真实 ISRUC pretrain checkpoint（seed 4321，subject 1 的 8 个 sequence）和真实 FACED pretrain checkpoint（seed 4321，subject 1 的 8 个 sequence）均已通过 EdgeForge instrumentation。输出文件分别为 `encoded-isruc-pretrain-brainuicl-20260915.json` 和 `encoded-faced-brainuicl-20260915.json`。它们是单被试的层级诊断，不能作为跨被试 identity probe。

ISRUC 的 fusion、Transformer、classifier-input effective rank 分别为 6.777、12.116、13.306；Transformer 的 stable rank 为 2.437。实际 BrainUICL attention 是 `softmax(dim=1)` 的跨 head 归一化，归一化 entropy 为 0.7988，key-axis entropy 为 2.9034；feedforward ReLU 的 dead fraction 为 0.6804。FACED 对应 effective rank 为 118.016、49.283、39.924，Transformer stable rank 为 4.654，跨 head entropy 为 0.5538，key-axis entropy 为 2.5008，最大 attention probability 为 0.9962，feedforward ReLU dead fraction 为 0.5525。两个数据集的谱和 attention 明显不同，不能把数值横向解释成某个数据集“更容易 LoP”。

这一步证明了编码后表征可以被逐层测量，并且不同输入契约会产生不同的谱、激活和 attention 结构。“编码后是否仍能识别同一被试”已经在所有当前 processed sequence/trial 上完成；完整的逐 tap probe、混淆矩阵、PCA、split manifest 和运行日志位于 `../subject-id-probe-20260915/`，并以 `SUBJECT_IDENTITY_REPORT-20260915.md` 汇总。当前实验仍是 group-disjoint 而非 session-disjoint，因此不能跳过后续的 session 和 class-balanced 控制。

## 逐层可视化与身份学习检验

每个 tap 应保存 epoch token 和 sequence/trial pooled 两种粒度。对 `[B,T,D]`，`D` 是 feature axis，`B×T` 是 epoch observation；sequence 级别对 20 个 token 取 median 或 mean。每层绘制标准化 PCA/UMAP，分别用 subject 和 task class 着色，并同时绘制 within-subject radius、between-subject centroid distance、class-balanced probe accuracy、session-disjoint probe accuracy、effective rank 和 CKA/Procrustes 漂移。已有随机初始化架构图位于 `docs/eeg-architecture-lop/brainuicl-subject-stability-audit-20260914/`；真实 checkpoint 的层级谱和诊断位于本目录的两个 `encoded-*.json`。

模型是否学习个体特征取决于训练目标和数据：只要个体差异与标签、采集条件或稳定的通道关系相关，监督分类网络就可能在 CNN、fusion 或 Transformer 中保留这些信息；如果这些信息与任务无关且被归一化、正则化或瓶颈压掉，后层身份 probe 可能接近机会水平。因此应把 subject identity 作为只读的辅助 probe，而不是加入主分类损失：在训练 sequence 上拟合线性 probe，在未见 sequence/session 上评估，并与输入统计特征、冻结随机网络和标签置换基线比较。若需要个体不变表征，再引入 subject-adversarial 或 domain-invariant 正则，并同时检查睡眠/情绪分类准确率是否下降。

## 对 LoP 研究的边界

相邻差分 RMS 和身份 probe 是数据/表征诊断。相邻差分 RMS 高通常表示更强的高频变化、噪声或边沿；它不是 LoP outcome。LoP 仍需在相同任务、split、优化器和固定更新预算下比较 fresh 与 warm，并跨至少三个独立 seed 重复。编码层 effective rank、attention entropy、Jacobian/NTK、死单元和身份可分性只能作为机制变量，不能替代 `fresh_gap_final`、AULC gap 或旧任务 retention。

本轮数据级结果的机器可读文件为 `identity-fingerprint-audit-20260915/manifest.json`；FACED 旧的服务器版结果也保留在 `docs/eeg-architecture-lop/subject-fingerprint-server-20260913/FACED-REPORT.md`。原始 BDF、NPY 和 checkpoint 均未复制到 EdgeForge Git 仓库。
