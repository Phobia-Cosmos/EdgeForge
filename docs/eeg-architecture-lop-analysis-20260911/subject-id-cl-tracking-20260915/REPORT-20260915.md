# ISRUC continual-learning checkpoint identity tracking（2026-09-15）

本轮把同一个 80% known-subject / 20% unseen-subject split 和同一个 linear probe 固定，只替换 BrainUICL checkpoint。`Pretrain` 是基线；`EpochNum_2_cpc/individual_1` 和 `individual_38` 是已有 continual-learning checkpoint，分别对应 stream 中吸收不同 subject 后的模型状态。所有结果是 sequence-level（20 epoch median），不把 sleep/emotion label 作为目标。

| checkpoint | EEG branch top-1 | Transformer L1 | Transformer L2 | Transformer L3 | classifier input | logits |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Pretrain | 0.7541 | 0.5284 | 0.4948 | 0.4652 | 0.3022 | 0.0777 |
| individual_1 | 0.7645 | 0.5638 | 0.5267 | 0.4988 | 0.3155 | 0.0806 |
| individual_38 | 0.7715 | 0.5615 | 0.5249 | 0.5058 | 0.3306 | 0.0829 |

Unknown-subject AUROC 也随 checkpoint 发生变化：EEG branch 为 0.6633（Pretrain）、0.6669（individual_1）、0.6919（individual_38）；Transformer layer1 为 0.5871、0.5945、0.5966。这个小样本 checkpoint 对照提示：持续学习更新后，身份 probe 分数和未知拒识能力可能上升，即模型可能在吸收新 subject 数据时重编码了 subject-specific characteristics；但差异还不能称为“模型记住了某个人”，因为 checkpoint 的训练顺序、更新预算和 task accuracy 需要同时审计。

## 如何回答 RQ3

这一步已经把 RQ3 从“只看 frozen pretrain”推进到“跨 continual-learning checkpoint 的固定-probe 对照”。严格结论仍需：至少 3 个 model seed；每个 stream step 的 identity probe；被吸收 subject、旧 subject、未见 subject 三组分层；task accuracy/forgetting 与 identity accuracy 同步记录；以及随机更新和 replay 对照。如果 identity probe 上升但 task accuracy 不变，说明表示中可解码的 subject 信息增加；如果 identity probe 下降但 task accuracy 保持，可能是任务瓶颈压缩或 subject-invariant 化；两者都下降则可能是表征退化，不能直接归因于 LoP。
